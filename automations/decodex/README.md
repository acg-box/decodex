# Automation support assets

The [portfolio](../portfolio.toml) retains only the daily upstream Maintainer.
The Content Manager and Xurl Publisher schedules and prompts are retired.
See [upstream maintenance](../../openwiki/operations/codex-upstream-autopilot.md).

`scripts/config/` validates the portfolio. `scripts/social/` retains schemas used
by the Publisher implementation and historical publication records. Schema actor
identities do not register an automation. Preserve existing receipts and budget
ledgers; see [Publisher contracts](../../openwiki/integrations/radar-publisher-contracts.md).
