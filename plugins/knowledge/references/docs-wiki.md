# Docs Wiki

Use for `docs/` navigation, indexes, links, and deduplication; use `okf-layer.md` for
portable OKF/LLM Wiki bundles.

Read `README.md`, `docs/index.md`, `docs/policy.md`, then smallest lane index and
owner. Lanes: `spec`, `runbook`, `reference`, `decisions`, `research`, `evidence`.

Rules: one authoritative concept per claim; link repeats; update indexes; use
`related`; keep `docs/research/` non-authoritative until promotion; after promotion,
superseded research routes as provenance. Update `docs/log.md` for navigation,
promotion, naming, policy, or maintenance.
