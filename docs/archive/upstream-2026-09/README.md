They were consolidated from `work/` and the root scan journal at repository revision `e6a669139`. Their old completion wording, source names, versions and temporary paths are historical; they do not create a new task or prove current runtime acceptance.

Start with the [OpenWiki quickstart](../../../openwiki/quickstart.md), [product decisions](../../../openwiki/decisions/upstream-product-scope.md), or [acceptance boundaries](../../../openwiki/testing/upstream-acceptance-boundaries.md). Current documentation is maintained in OpenWiki. This archive receives corrections to links or historical attribution, not new product instructions.

The [migration map](migration-map.tsv) records all 185 original work files and the root scan journal. Original hashes describe the pre-move bytes; Markdown archival notices and relative links were then updated. Git retains the original versions. No application state, test result or recorded limitation was discarded.
