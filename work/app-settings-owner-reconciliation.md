# App settings and legacy outcome reconciliation

Classification: optional App policy and tool-visibility controls, with core
saved-state and no-replay requirements when these controls are retained.
Read the complete inherited and current runtime App-settings, runtime exposure
and desktop App-settings files. Verify their snapshot hashes. Keep native Codex
as the configuration and tool-filtering owner.

## Request-bound App settings

The current runtime retains exact event, work, thread, process, connector and
connection identity. A yielded tool request can retain an older turn identity;
its live native request guard remains authoritative. Child requests require the
existing native ancestry and owning-thread checks. Metadata identifies the
connection; model tool arguments cannot replace it.

The writable native file, version and raw override now join the review identity
and shared App/Hook reservation. A resolved tool request remains readable, but
cannot authorize another request-bound write. Saving an override never answers
the tool request. The saved-connection editor is additive and calls the same
submission owner for an existing native connection override.

The adapter validates the native save acknowledgment and version independently
of subsequent reads. The service records that acknowledgment before a caller
read can fail or its source can change. This replaces the old combined save/read
result: a failed later read does not erase a confirmed save. Effective policy is
still separate; a higher configuration layer can override the saved value.
Known pre-dispatch refusals remain rejected, ambiguous writes remain unknown,
and neither is retried. Shared recovery reads the original target and requires
process-death evidence before another owner can settle an uncertain write.

The old reservation-only App record has no native file scope or result. Preserve
those rows; do not fabricate a modern receipt, file identity or successful save.
The current request guard and fresh source-bound review remain required for an
explicit edit. This review adds no migration or automatic write.

## Connector exposure

Retain exact installed-connector identity, owned native thread, current settings
guard, native configuration fingerprint and source revision checks. Unknown read
values remain displayable; writes retain the bounded supported surface list.
Absent and empty preferences stay distinct. A no-op does not reserve a write.

The shared App/Hook journal replaces the inherited exposure-only writer. It
arbitrates by actual writable file and records saved, overridden, rejected and
unknown outcomes. Original connector, link-free target and expected version stay
bound to the reservation. No local tool filter or second writer is restored.

The old exposure result reader was missing. Restore a read-only query in the
current database owner, bound to the original work, thread and connector. If no
modern shared receipt exists, expose the old reserved, saved, rejected or unknown
outcome. Include its event identity and state in the fresh review token. A changed
historical result invalidates a prior review. A modern shared receipt takes
precedence. The panel says "Last recorded configuration write" because the legacy
record has no shared-file identity.

Do not infer current preferences from historical requested values. Native reads
still supply effective and stored preferences. Do not translate old outcomes into
modern pending writes or replay them. A new, explicit, freshly reviewed edit uses
the current shared journal and native version check. The original unknown result
remains unknown; that later edit does not prove the old write succeeded.

## Desktop App settings

Keep all eight inherited approval/reviewer actions and explicit inheritance.
The current panel distinguishes user and effective values, shows the shared
receipt, and requires a new read after every edit, including a lost reply.
It sends once and reads state again. It does not answer the pending request.
Native child navigation cannot operate the parent's panel.

The old combined disconnect helper moved to independent reset owners in profile,
workspace, failed-snapshot and stale-service paths. The panel's epoch and current
request checks reject late results. Source, thread, turn, dispatch or pending-event
changes invalidate review. Current display helpers are also used by the additive
saved-connection editor; no inherited choices are removed.
